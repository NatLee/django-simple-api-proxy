Django Simple API Proxy

One route of your Django site becomes the door to another server.

$pip install django-simple-api-proxy
Client
Talks to your site
GET /my_test_route/items/7
a browser, your frontend, an app or curl
Your Django site
APIProxy
/my_test_route/… → /get/…
checks the login if you ask it to,
adds an API key if you want one
Target site
Any HTTP server
https://httpbin.org
GET /get/items/7
Pass-through mode default since 2.0

Everything goes through as it is: method, path, query, headers and any body; the status, headers, cookies and body of the reply, redirects too.

JSON mode PROXY_PASS_THROUGH = False

The 1.x behaviour: JSON in, JSON out, adds the caller's username, always HTTP 200, {"status": "error"} on failure.
